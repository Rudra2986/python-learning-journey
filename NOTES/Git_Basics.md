# Git Basics

## Initialize Git

```bash
git init
````

Starts Git tracking.

---

## Check Status

```bash
git status
```

Shows current project status.

---

## Add Files

```bash
git add .
```

Adds all files for commit.

---

## Commit Changes

```bash
git commit -m "message"
```

Creates save point.

---

## Connect GitHub Repo

```bash
git remote add origin REPO_URL
```

Connects local project to GitHub.

---

## Push Code

```bash
git push
```

Uploads code to GitHub.

---

## First Push

```bash
git push -u origin main
```

---

## Pull Changes

```bash
git pull
```

Downloads latest changes.

---

## Normal Workflow

```bash
git add .
git commit -m "Updated project"
git push
```

---

## Important Notes

* Commit frequently
* Write meaningful commit messages
* Push projects regularly
