````md
# Input and Output

## Output

```python
print("Hello World")
````

---

## String Input

```python
name = input("Enter Name : ")
```

---

## Integer Input

```python
age = int(input("Enter Age : "))
```

---

## Float Input

```python
price = float(input("Enter Price : "))
```

---

## Example

```python
name = input("Enter Name : ")
age = int(input("Enter Age : "))

print("Hello", name)
print("Age :", age)
```

---

## Type Casting

| Function | Purpose            |
| -------- | ------------------ |
| int()    | Convert to integer |
| float()  | Convert to float   |
| str()    | Convert to string  |
| bool()   | Convert to boolean |

---

```python
num = "10"
```
