# Variables

## What is Variable?

A variable stores data in memory.

---

## Syntax

```python
name = "Rudra"
age = 20
height = 5.8
````

---

## Rules for Variable Names

### Valid

```python
user_name
age2
studentMarks
```

### Invalid

```python
2name
user-name
class
```

---

## Common Data Types

| Type  | Example |
| ----- | ------- |
| int   | 10      |
| float | 5.8     |
| str   | "Hello" |
| bool  | True    |

---

## Print Variable

```python
name = "Rudra"

print(name)
```

---

## Check Type

```python
age = 20

print(type(age))
```
